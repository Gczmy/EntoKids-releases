# EntoKids Android 测试版

本仓库只分发 Android 安装包、签名更新清单和版本说明，不包含 EntoKids 应用源码。源码仓库保持私有。

请从 Releases 下载最新开发测试包。包名为 `org.entokids.app.dev`，包含现有课程图片和配音；课程仍属开发草案，正式内容审校与真机验收尚未完成。

首次需手动安装支持更新的版本，后续由家长区主动检查、下载并交给 Android 系统安装。旧测试包签名可能不同，请先保留原有安装，依据具体安装提示处理；卸载会清除本机记录。

更新清单：`channels/development/update.json`。清单采用 EntoKids 专用 RSA 签名，APK 始终使用固定签名证书。GitHub 网络可达性取决于实际网络，国内镜像后续补充。
